# Ephora Viewer

Ephora Viewer es un visor de Second Life para Android, en construcción.

No es todavía una aplicación funcional completa. Este repositorio se está armando de forma ordenada, subiendo solo lo necesario para compilar una única aplicación Android.

## Base del proyecto

- Está basado en **Lumiya**, el visor de Second Life para Android.
- Toma ideas y trabajo previo de **Linkpoint**, de Kaleaon (https://github.com/Kaleaon/Linkpoint).
- A partir de ahí, Ephora Viewer sigue un camino propio, con correcciones e implementaciones nuevas.

Linkpoint, en su estado actual, tiene fallos y no está terminado. Por eso aquí no se da por hecho que algo funciona solo porque ya existía en ese código: cada función debe revisarse, comprobarse y documentarse antes de presentarse como lista.

## Reglas de trabajo

- Solo se sube y se compila **una app Android funcional**: Ephora Viewer. No se mantienen varias builds juntas en este repositorio.
- Nada de funcionalidad ni promesas falsas. Lo que se diga que está implementado debe estar comprobado y analizado.
- La implementación debe basarse en información sólida: la documentación y las wikis de visores de terceros de Second Life, especialmente para la conexión, el renderizado y el avatar.
- El trabajo se hace por pasos verificables, empezando por dejar el repositorio y la compilación en GitHub Actions en orden.
